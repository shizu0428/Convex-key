矩形の1つの頂点から対角に向かってなだらかな弧を描く、独自のコンベックスキーキャップです。 親指が斜めから触れた際にも自然に沿う心地よい指ざわりを実現しつつ、対角に走る隆起によって隣接するキーとの区別が感覚的に行えます。
