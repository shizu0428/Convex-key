## 特徴

* **快適な指触り**: 親指が斜めから触れた際にも自然に沿う、心地よい打鍵感を実現。
* **高い識別性**: 対角線上に走るゆるやかな隆起により、ホームポジションからでも隣接キーとの境目を感覚的に判別可能。
* 狭ピッチ（16.5mm × 16.5mm）に対応。ステムはchocV2、MX互換です。

* **造形の向き**: ファイルを開いた状態のまま（キーを立てた状態）
* **ノズル径**: 0.4mm
* **積層ピッチ**: 0.08mm
